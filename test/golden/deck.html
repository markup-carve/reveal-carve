The pitch

  • Code samples need no escaping
  • Layout is markup, not embedded HTML
  • Stepwise code highlighting from a fence attribute
  • The source is checkable before anyone presents it

Each bullet arrives on its own key press because the slide carries a %% fragments directive.

1. Code, unescaped

$articles = $this->Articles->find()
    ->contain(['Users'])
    ->where(['published' => true])
    ->orderBy(['created' => 'DESC'])
    ->all();

In HTML this slide would need &gt; eleven times. Every one of them is a chance to break the sample.

2. Highlight the line you are talking about

$query = $this->Orders->selectQuery();
$query->contain(['Customers'])
    ->where(['status' => 'open']);
$total = $query->count();

Press the right arrow: the deck walks the three steps written in the fence’s attribute line.

The attribute line is Carve. reveal reads it on the code element, so the plugin moves it there.
