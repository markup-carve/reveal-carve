# reveal-carve docs

- [Getting started](getting-started.md) - install, scaffold, watch, build, print,
  publish.
- [Authoring slides](authoring.md) - code blocks, chapters and includes,
  containers, footnotes, timing, footers and themes.
- [Extensions](extensions.md) - what is on without asking, and what a diagram
  fence needs from the page.
- [Printing and publishing](publishing.md) - the PDF export, publishing without
  serving a stale deck, and decks that need no network.
- [Frontmatter](frontmatter.md) - the settings a deck source carries itself.
  Written in Carve: [frontmatter.crv](frontmatter.crv) is the original.
- [Training decks](training.md) - the `--preset training` starter, its managed
  renderers and its commands.
- [Reference](reference.md) - every directive, flag, plugin option and layout
  class, and the keys a slide answers to.
- [Markdown or Carve](markdown-vs-carve.md) - the comparison, including the
  cases where Markdown is the better choice.

The [demo site](https://markup-carve.github.io/reveal-carve/) runs one source
through the build step, the runtime plugin, the handout and the PDF export.
